# greenwichbooth

Greenwich Vietnam themed camera booth for prospective high-school students.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Current MVP runs fully in the browser: webcam/upload input, themed frames, filters, stickers, PNG download, and Web Share where supported.

The QR printed on exported photos opens the booth page. A QR that downloads the exact captured photo from another device needs hosted storage/API later.
